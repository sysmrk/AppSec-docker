New manual image scan

No CI/CD required. Start with a real registry image, review findings, then decide what happens next.

Enter a reference accessible to Docker on the worker. This does not upload an image archive.

What happens next?
  1. Trivy scans the image and generates an SBOM
  2. AppSec checks the policy and saves the results
  3. You review the CVEs and choose to finish or approve patch + registry push
  4. If approved, Copa patches, pushes, rescans and compares findings
Patch and push are never automatic.
