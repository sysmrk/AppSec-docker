START HERE

New manual image scan

No CI/CD required. Start with a real registry image, review findings, then decide what happens next.

Enter a reference accessible to Docker on the worker. This does not upload an image archive.

What happens next?
  1. Trivy scans the image and generates an SBOM
  2. AppSec saves the initial CVEs and SBOM; policy recommendation comes only after patching
  3. You review CVEs and approve a local patch (optional)
  4. Copa patches, rescans and compares; you then keep it locally or separately approve a registry Push

A readiness check validates configuration and Worker heartbeat, not actual image pull or registry credentials.
